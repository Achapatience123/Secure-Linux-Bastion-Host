# Secure Linux Bastion Host on AWS

## Executive Summary

This project demonstrates the deployment and hardening of a Linux Bastion Host on AWS.

The goal is to build a secure administrative entry point while applying DevSecOps security controls such as restricted access, firewall protection, logging, and system hardening.
