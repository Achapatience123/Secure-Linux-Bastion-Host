# Final Security Assessment Report

## Project

Secure Linux Bastion Host on AWS

---

## Executive Summary

This project focused on deploying and securing a Linux Bastion Host within AWS.

The Bastion Host acts as a controlled administrative entry point designed to reduce attack surface exposure and improve infrastructure security.

The implementation followed DevSecOps principles by integrating security controls directly into deployment, access management, validation, and documentation processes.

---

## Architecture Summary

Components:

- AWS EC2 Instance
- Ubuntu Server 26.04 LTS
- Security Groups
- SSH Key Authentication
- UFW Firewall
